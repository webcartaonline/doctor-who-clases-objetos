# Doctor Who — Clases y Objetos en Python

Tarea de clase de **Juan Camilo Piamba Uribe**: un programa de consola que explica
**clases, objetos y herencia** usando personajes de la serie Doctor Who.

## Cómo ejecutarlo

Solo hace falta tener Python instalado (no usa librerías externas):

```
python doctor_who.py
```

## Qué se trabaja

- **Clase padre** `Personaje` y **clases hijas** `Doctor`, `Acompanante` y `Villano` (herencia y `super()`).
- **Clase independiente** `Tardis`, que no hereda de ninguna otra.
- **Objetos** creados a partir de esas clases, con sus atributos y métodos.
